## How to run (placeholder)
```bash
# 1) Prerequisites
java -version   # should be 17+
mvn -version

# 2) Run tests
mvn test
mvn -q -DskipTests=false test

# 3) Start application
# Optional: override port
export APP_PORT=8080
mvn spring-boot:run

# 4) Try demo endpoint
curl -X POST http://localhost:8080/api/v1/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"Prepare interview panel","description":"Collect candidate scorecards"}'

# 5) OpenAPI docs
# Swagger UI: http://localhost:8080/swagger-ui.html
# OpenAPI JSON: http://localhost:8080/api-docs
```

### Environment variables
- `APP_PORT`: server port (default: `8080`)

### Design choices (why)
- **Clean architecture boundaries:**
  - `domain`: core business model and rules
  - `application`: use cases and ports
  - `infrastructure`: adapters/technical details
  - `interface/rest`: controllers, DTOs, API contracts
- **Validation and security mindset:** request DTO constraints with centralized error handling.
- **Observability baseline:** structured error payloads + server-side logging in global exception handler.
- **Pragmatic persistence choice for Day 01:** in-memory repository keeps focus on architecture, not ORM setup.

### How to test

mvn -q -DskipTests=false test
